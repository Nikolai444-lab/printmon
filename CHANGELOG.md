# История версий

## 0.9.7 — 30.09.2026

- мастер первого запуска: подсеть больше не прописана заранее — программа сама определяет
  сетевые адреса компьютера и спрашивает, сканировать ли их (ответ запоминается);
- пример конфига больше не содержит ничьих адресов.

## 0.9.6

- кнопка «⏹» — остановка программы прямо со страницы: опрос прекращается, база закрывается,
  порт освобождается. Закрытие вкладки браузера программу не останавливает.

## 0.9.5

- при запуске сама открывается вкладка браузера со страницей программы (поле `openBrowser`,
  разовый ключ `-noopen`); вкладка открывается только после того, как порт успешно занят.

## 0.9.4

- порт страницы по умолчанию — 49321 вместо 8080 (8080 часто занят другими программами);
  старое значение в конфиге уводится на новый порт автоматически;
- понятное сообщение в логе, если порт занят.

## 0.9.3

- крестик в окне добавления принтера (раньше окно закрывалось только по Esc);
- колонка «Удалить»: принтер убирается из таблицы, его история стирается, а адрес из
  опрашиваемой подсети попадает в исключения и не возвращается при следующем сканировании.

## 0.9.2

- несколько подсетей сразу (`subnets`); список `hosts` дополняет подсети, а не заменяет их;
- добавление принтеров и правка кабинетов из интерфейса, обмен таблицей кабинетов в CSV;
- сортировка по любому столбцу; номер кабинета в блоке «пора заказывать картриджи».

## 0.9.1

- кабинеты через поле `locations`, значения от самих принтеров фильтруются от мусора;
- легенда цветов над таблицей с подписанными порогами;
- светлая и тёмная темы с запоминанием выбора.

## 0.9.0 — первая рабочая версия

- опрос парка по SNMP, история уровней в SQLite, тренд и прогноз «осталось N дней»;
- веб-страница с таблицей, поиском, фильтрами и блоком предупреждений;
- поддержка цветных аппаратов (четыре картриджа) и устройств, отдающих сырые счётчики.
